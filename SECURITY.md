# Security policy

<!-- Project: Mark44928/SnakTUI -->
This project runs locally, performs no network calls (there is no phone-home anywhere), and stores no credentials.

To report a vulnerability (e.g., an unsafe file operation, a command-injection vector, a config-parse issue):

1. Preferred: open a [GitHub Security Advisory](https://github.com/Mark44928/SnakTUI/security/advisories/new) on this repository (private disclosure).
2. Or email the maintainer at the address listed on the owner profile.

Include: platform + version, steps to reproduce, and impact if you can. We will acknowledge, fix, and credit (or keep anonymous, your choice) — usually quickly for a solo-maintained hobby project.

Do not disclose publicly until a fix is available.
